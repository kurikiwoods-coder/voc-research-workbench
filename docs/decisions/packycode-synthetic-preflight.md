# PackyCode 独立合成接口预检授权

2026-11-25，项目负责人在 G-1-R-B-P 批准独立合成契约预检。适用范围是当前个人电脑工作台的一次人工虚构输入，固定 PackyCode `typesafe-officially`、`jev-1.14.0` 和 `POST https://cf.api.fan/v1/systemone`。现有工作台 API 诊断入口、外发校验和正式研究批次继续执行原门禁。M06 冻结及 SQLite v8 适用。

- 本机命令输入为已核验的许可、权限、额度和预算记录。发送正文、问题和端点来自固定夹具。负责人按供应商账户实际材料填写核验记录，代码检查结构、有效期、固定通道、当前 DPAPI 密文版本和预算计算，账本保留材料摘要。程序通过现有 DPAPI 机制在 HTTPS 传输中使用凭证。
- 独立 SQLite v1 使用固定批次键。执行前领取批次，写入每次分片预约后才调用现有网络传输。账本已领取时，读取原回执。限流、权限错误、故障和程序中断均不得重试或更换供应商。进程中断后的预约代表可能已发送，须用账户用量核对。

- 回执保留固定夹具、分片编号、HTTP、可辨识模型、题号对齐、三类响应的结构化允许字段和实报输入输出。扣费和余额由账户证据核对，未知时为空。正式研究计数为零。
- 正式公开语料外发、编码、发布和正式 G-1 验收依据实际账户供应商审批及同一正式批次 C0-1 至 C0-6 全部通过。M08 和 M12 等待后续授权。
