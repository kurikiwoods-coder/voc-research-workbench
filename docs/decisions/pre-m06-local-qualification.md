# Pre-M06 数据资格和迁移处理

- 存量 SQLite v5 增量到 v6 时只更新撤销视图。审核事件、批次、指纹、原文及其引用维持历史可追溯性。当前资格重新核对已存审核和源许可，明确撤销继续作用于同项目的同源文档。
- URL 片段是同一文档的位置标记，来源和许可证明的身份计算省略片段，保留实际查询。导入文件保存的完整链接作为原始引用留存。证明更换仍须符合当前审核规则。
- 工作台需为新凭证核对对应的供应商审批。旧本机审批存档保留，绑定只在本机进行。外发和正式计数继续按 PDT 处理，内部 CX 本机隔离。
- 后续模块使用实时资格接口。历史原话和复核需要访问受控存储。SQLite 和备份物理清理按来源政策独立验收。
