# M09-B 本机 BERTopic 复验

2026-11-27，在 Windows 11 Enterprise 25H2（26200）、CPython 3.12.9、CPU 的隔离环境中复用 M09-A 固定 MiniLM 批次。依赖锁和模型资产摘要见 [M09-A](../m09-a/README.md)。

## 接口

`cluster_offline` 复用 M09-A 的预处理、脱敏、精确证据版本、稳定文档行与向量。BERTopic 0.17.4 使用预计算向量，UMAP 0.6.0 降维，HDBSCAN 0.8.44 聚类，c-TF-IDF 提取加权词。两种版本共用发现层。默认种子 42，邻居 10，降至 2 维，`min_dist=0.05`，最小簇 5 条、最小样本 3 条。结果保存请求与实际参数、软件版本、Embedding 运行 ID、模型配置、固定注册表、语种及向量摘要。

使用 jieba 0.42.1 的内置词典及固定停用词处理中文，英文使用 scikit-learn 停用词。BERTopic 的语言设置为 `multilingual`，使 c-TF-IDF 保留中文词。停用词处理后无词项的行保留其向量及文档映射。全批无词、样本不足或无有效簇时可以返回零个候选主题。标记 `-1` 保留在文档分配中。返回前按原作用域重查许可、精确片段、注册表版本及模型配置。

## 实测

原生 Windows 11 的定向和上游回归 86/86，失败 0，跳过 0，退出码 0。受控 Python 进程观察到 0 次非回环 socket 或 DNS 尝试。实际模型权重与依赖下载安装属于部署准备。真实研究 API、费用和正式分母增量均为 0。

首个夹具含两品类、中英文共 22 条合成证据。默认参数分出「离线操作」「可拆部件洗碗机清洁」两个主题，覆盖各 8/8、纯度各 8/10，两条标记为离群。主题分别包含 `offline`、`离线` 和 `dishwasher`、`洗碗机`。倒序提交相同证据后按稳定 ID 复跑，完整运行结果一致。

实际聚类专项 6 项，3 通过、3 未通过、跳过 0，诊断整组退出码 1。默认参数的首个夹具、纯离群和空词表通过。预先固定的替代参数下，离线主题纯度为 8/11。独立夹具的提醒音主题纯度在默认和替代参数下分别为 8/13 和 8/12。三项低于本轮诊断阈值 75%，说明不相关语料仍可能进入候选簇。全部双语场景复跑一致。该阈值用于合成夹具诊断。ROADMAP-V2 的 M09-B 工程验收涵盖实际聚类、主题提取、参数记录及回放。正式 G3 质量继续依原定盲测与真实小样本审核。[参数与质量诊断](exploratory-clustering.md)

复用 M09-A 的本地环境、`$m09Python` 和 `$m09ModelDir`，在仓库根目录执行。

```powershell
& $m09Python scripts/verify-m09-offline.py $m09ModelDir docs/evidence/m09-a/model-assets.json 'test_m09_actual_topics*.py' --app-site-packages .venv/Lib/site-packages
```

追加 `--topic-quality-diagnostics` 可运行三项保留的阈值诊断。使用当前锁定模型及默认配置时，这组三项会报告前述纯度不足。

## 接续
