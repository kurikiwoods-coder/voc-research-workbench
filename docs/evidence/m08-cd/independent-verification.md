# M08-C/D 独立复审

独立审阅覆盖 M08-C 逐对象权限及正文角色、M08-D 事务、在途预约和恢复、M06 冻结资格、采样漏斗及来源去重。复审复现了第二批启动碰到已冻结范围触发器的问题，并检查了 M04 提交至 M05 审核的故障边界。合并修复后运行任务账本、采样集成及全量回归。

| 检查点 | 复核证据 |
| --- | --- |
| 平台及正式权限 | 逐对象的访问、存储、研究与传输独立判断。YouTube 仅用已获准的 `textOriginal` 工程夹具。Reddit 受阻。工作台正式入口 403。 |
| 状态及并发 | 同一账本同时执行只预约一次。子进程异常退出，发送结果未知时保留预约。已落库本机导入回执可读取并补结算，相同回执并发到达只结算一次。 |
| 批次原子性 | 注入第二条 M05 核验失败后，M04 批次及 M05 快照均回滚。另在批次成功后模拟任务回执写入中断，重启后从原请求关联的本机回执恢复，数据库保留一份批次。 |
| 资格及精确证据 | 复用 M05 当前可见性、许可、批次与冻结范围，并验证 M06 精确码点区间。合成角色保留，权威 M/E 和版本保持空值。来源撤销后的访问和恢复均失败关闭。 |
| 统计与身份 | 分阶段等齐权威回执后计数。失败主搜索仅可由同批次成功替代回执补全。重复 URL 保留多引擎回执，跨站同文只标待审。 |
| 本机界面 | 独立浏览器验证使用 Chrome 157、本机隔离服务及禁用外发的夹具。覆盖键盘、小屏、重启后恢复、料批回读与正式入口关闭。 |
