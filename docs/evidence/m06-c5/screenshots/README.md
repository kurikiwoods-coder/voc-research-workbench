# C5 分母对账界面与本机 API

进入中文工作台的「三层关系」，选择「分母对账」。工程视图从同一统计响应呈现分母链、六桶分布、已发布主任务、候选输入排除账、未切片整行和两条对账差额。界面显示项目、注册表、片段、冻结范围映射、产品目录、统计口径与 UTC 取数时间。

项目和冻结范围使用现有选择器。产品品类、任务大类和用户意图可多选。来源、批次、置信度支持多值。UTC 结束日不包含当日，发布时间与采集时间由用户明确选择。数值不可用时显示「不可用」，已核验的空结果显示 0。异常证据经现有抽屉和当前授权再次核验。拒绝访问或证据失格时，抽屉及旧结果会清除并触发重新查询。

`GET /api/studies/{study_id}/denominators` 要求显式 `mode`，以 `M06-B-F.1` 计算整个授权切片。接口接收重复筛选参数，拒绝分页参数。工程合成夹具中有 3 个合格唯一发生，均处于其他待处理桶，两个对账差额为 0。M08 采样台账缺项返回 `null`。G-1 未满足时，正式模式返回 `availability=unavailable`，计数和对账字段均为 `null`。独立合成回执通过测试接口在临时 SQLite 上演练。

本机 HTTP 专项验证了产品并集、同一证据须同时满足产品与批次筛选、UTC 偏移标准化、越权项目与不存在项目的相同 404，以及角色头不能赋权。单独的隔离应用请求验证了非回环请求及伪造转发头返回 403、无效 Host 返回 400、无可信项目授权返回 404，四类响应均带 `Cache-Control: no-store`。
