# M09-D 隔离聚类评估规约 v1

本实验是研究质量诊断。生产基线及历史 TopicRuns 冻结于工程交付提交 112474a9225b979d00d5f969403f9b012f8dcbb3，0.60 仍为实验阈值。所有拟合仅接收含 ID、语言和人工合成文本的输入文件。评分是独立命令，核验输入摘要、版本和逐条 ID 后才读取金标。原 M09-D 已公开盲测仅用于历史复算。新留出集由独立编写者冻结并分离保管。[样本划分](dataset-plan.md) · [历史复算](historical-audit.md)

## 对照设计

固定获准的本机 multilingual MiniLM、原 NFKC/脱敏/空格处理、向量归一化和模型输入长度。每个划分先按固定 ID 排序，共计算一次向量，五个策略共享它。同一批的主比较采用种子 42，其余两次以种子 17、67 同时变更 UMAP 种子及输入顺序，检验综合敏感性。记录实际运行时、向量摘要、CPU 与墙钟。首个 BERTopic 测量含共享进程首次导入和可能的 JIT，各种子耗时仅用于定位成本量级。

| 策略 | 参数 |
| --- | --- |
| baseline | 现用 BERTopic，UMAP 邻居 10、维数 2、最小距离 0.05，HDBSCAN 最小簇 5、最小样本 3 |
| centroid_060 | 保留基线簇，现有诊断余弦低于 0.60 的成员转离群 |
| density_5d | 相同 BERTopic，将邻居改 8、UMAP 维数改 5、HDBSCAN 最小簇改 4、最小样本改 2 |
| cosine_055 | 峰值簇候选用原向量的余弦平均链接，距离截断 0.55，保留至少 4 条的簇 |
| cosine_055_margin | 在 cosine_055 上补充成员留一质心相似度至少 0.40，对其他候选质心的优势至少 0.05，重查最小簇大小 |

开发集用于诊断差异。验证集用于按多指标观察单一推荐方案的可迁移性。方案与最终门槛在读取留出集标签前冻结。模型、分词、去重与上下文方案的查证记录单独留存，本轮实测主要隔离聚类和弃权变量。[技术比较](technical-options.md)

## 评分

- 按金标意图与候选簇的交集大小进行匈牙利一对一最大重叠匹配。逐意图纯度为匹配命中数除以该簇全部成员，召回为命中数除以该意图全部金标。无匹配簇的纯度记空，召回记零。另报全部簇多数正类命中数除以全部已分配样本的加权纯度，及所有匹配命中数除以全部正类样本的整体匹配召回。匹配存在并列时，逐标签归属需要结合成员重叠解读。
- 总覆盖用全部样本作分母，正类覆盖用所有正类样本作分母。空标签包括模棱、离群或不具备共同可执行意图的样本，空标签被分配的比例衡量弃权失效。候选需达匹配纯度 0.70、召回 0.50，且命中覆盖中英两种语言。未满足任一条件的候选计入未获支持候选比例。纯负例集的任何候选都计入误发现。真实研究的可执行性仍需人工判定。
- ARI 与 NMI 在正类样本上计算。每个预测离群样本单独当作单元素簇。候选一致性为跨扰动最优成员 Jaccard 配对之和除以两次最大候选数，未匹配候选计零。成员稳定性用同簇样本对 Jaccard。两次均无候选或同簇样本对时对应稳定性为空。空分母保留为 0/0，并在比较时视作无观察值。
- 保存每次主运行和扰动中逐样本的簇号、逐意图的计数、摘要及模型版本。合成数据在实际生产准入与 G3 口径下均独立登记。

## 独立留出验收计划

1. 负责人审阅诊断和单一待验策略。冻结该策略、基线、评估代码、两个留出输入摘要和留出金标摘要。先分别在混合及纯负例输入上运行一次预设试验，保全三个预设扰动的预测及摘要。
2. 由留出金标保管者用单独评分命令评分。混合批需同时满足整体匹配召回不低于基线、正类覆盖最多下降 5 个百分点、已支持意图数不下降、空标签被分配比例和未获支持候选比例各最多增加 2 个百分点，且平均同簇样本对 Jaccard 最多下降 0.05。当稳定性分母为空时报告未定义并人工复核。
3. 在护栏通过后，加权纯度或整体匹配召回至少改善 5 个百分点。纯负例批需同时满足误发现簇数和负例分配率均不高于基线。基线已经没有误发现时，挑战者也须保持 0 簇。人工检查双语命中、极短句、显式否定及各类弃权，保留全部失败例。
4. 仅做一次预先冻结的合成比较。证据不足或结果未达标准时保留基线，并用新的封存数据验证后续假设。正式 G3 仍待原定真实准入和人工验收。
