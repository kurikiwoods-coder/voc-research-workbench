# M07 缺陷与技术债

| 编号 | 等级 | 发现与处理 |
| --- | --- | --- |
| M07-01 | P2 | 合成来源撤销会使整个草稿详情读失败。详情改为保留已授权内容并移除失格引用，预检继续检查保存的依赖。独立反例确认。 |
| M07-02 | P2 | 注册表升版后旧草稿无法撤回。撤回按当前注册表及草稿修订核对，保留历史基础版。独立反例确认。 |
| M07-03 | P3 | 直接调用已撤回草稿的只读预检仍可得到校验结果。结果无写操作且 `formal_issuance=false`，界面不提供此操作。 |
| M07-04 | P3 | 既有 Starlette/httpx 测试适配警告继续记录。 |
| M07-05 | P1 | 草稿在来源失格后缺少显式置换入口。已提供引用替换及清除，实际浏览器资格撤销与重新编辑复验通过。 |
| M07-06 | P2 | 旧基础版草稿的界面撤回请求携带旧版本。已改用当前注册表版本，并在合成升版后复验。 |
| M07-07 | P2 | 次任务勾选项关联标签不准确。已调整标签，浏览器键盘及小屏复验通过。 |

合成测试验证范围见 [独立复审](independent-verification.md)。Windows 11 实机取证为环境缺项。[实机状态](windows11-manifest.json)
