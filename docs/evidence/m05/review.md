## 缺陷与合成回归

| 严重程度 | 修复前的实测 | 修复与回归 |
|---|---|---|
| 高 | 已核验记录排除时留空截止日，原截止日之后复核返回 200 并重新显示原话。排除时填写更晚日期也未受原期限约束。 | 根据既有审计历史在读取时计算有效期限。排除可缩短已有期限，空值或更晚的日期会沿用原限制。覆盖旧 SQLite 及截止日之后的复核拒绝。 |
| 高 | 受限记录的来源字段、审核自由文本和导入批次来源类型汇总仍可包含合成原话。 | 工作台和回执遮蔽相应内容。保留结构化审计、原始审计记录和固定计数。覆盖候选、详情、批次、重放及无原话错误 CSV。 |
| 高 | 显式无许可的描述仍可能被视为有许可。特殊 Amazon 来源地址和来源类型的组合可以遗漏评价字段校验。旧库中已核验的两条失格合成原话仍能显示，重复组被计为三条。 | 明确无许可或撤回许可的输入拒绝核验。Amazon 原话按地址或类型触发评价字段、已验证购买与美国市场校验。旧库读取时复核原话资格，语料与导入入口共用规则。回归验证重复组只剩一条有效原话。 |
| 高 | 审核已明确记录「来源许可已撤销」，但保留期内凭旧依据复核仍返回 200，原话也可再次加入重复组。 | 依据不可变审核历史识别许可撤销。在原话、导入和重复组入口同步限制，包括旧版错误复核的记录。完全相同的撤销提交只复用审计结果。 |
| 高 | 把相同来源 URL 和原话移到修改后的 CSV，撤销前取得的预览令牌及撤销后的新上传仍可读到原话并确认。已入库的跨文件副本也可继续参与去重。 | 按项目及来源 URL 遮蔽已有副本，并阻止含该 URL 的工作表预览和新确认。确认在写事务内重新检查。复测覆盖既有副本、新上传、旧预览令牌、独立 URL 及跨项目隔离。 |
| 中 | 来源 URL 中经编码的敏感值可能随来源元数据返回。 | 在显示和核验前过滤敏感来源字段与控制字符，保留可回查的原始记录引用。 |
| 中 | 批次排除、到期或审核后撤销后，完全相同的确认重试返回 409，无法取得既有回执。 | 先按项目、范围、文件摘要、工作表、配置和确认指纹查找既有回执。新的确认继续经过原有访问检查。并发复测确认撤销状态和记录数稳定。 |

测试仅用合成数据、临时 SQLite 和四份既有脱敏归档。真实研究 API 调用 0 次。具体回归见 [语料测试](../../../tests/test_corpus.py) 和 [导入测试](../../../tests/test_imports.py)。M05 的 SQLite 版本保持 v4，留存与审核历史继续依据原始行和追加式审核记录。逐源许可、物理清理、删除审计和正式样本证据按 [需求验收矩阵](../../requirements-matrix.md)登记。
