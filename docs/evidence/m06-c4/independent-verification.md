修复后专项 12/12 通过，失败及跳过均为 0，退出码 0。每个夹具完成 SQLite 完整性和外键检查。永久回归包含半发行中断、最终 COMMIT 失败、同连接资格变化、锁竞争、旧 WAL 快照、UTC 换日、丢失响应、同键重放、片段版过期、代理权限变更和历史代表依赖。
