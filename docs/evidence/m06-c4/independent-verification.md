# M06-C4 独立工程复审

## 入门探针

复审在独立 C3 源码归档和临时 SQLite 使用合成项目。三项通过，失败和跳过为 0，退出码为 0。

| 输入 | 实测 |
|---|---|
| 精确研究、片段、发生和证据引用及无可信主体 | 精确已许可引用有效。错误或未授权引用被拒，应用默认关闭。 |
| 直接证据、原帖和双方上下文共四条实际依赖 | C2 在同一主库连接复核四条。事务内撤回任一上下文，写拒绝且无部分残留。 |
| SQLite 延迟外键在最终 COMMIT 真实失败 | COMMIT 返回外键错误，外层执行 ROLLBACK。命令键及数据完整回滚，去除故障后同键重试成功。完整性 `ok`，外键违规 0。 |

## 实施复审

独立事务审查使用隔离源码、单独运行目录和真实 SQLite。组合命令初版对随命令附带的工程归属未逐条核对相应写授权，严重程度 P1。复现输入有全局发行和项目预检权，缺该条 R/M/E 的工程归属权限。修复后无权执行及重放均被拒，失败前后的命令、注册表、任务、意图、关系和代表证据相同。为同一操作者补发适用的精确项目授权后，合法组合成功。

修复后专项 12/12 通过，失败及跳过均为 0，退出码 0。每个夹具完成 SQLite 完整性和外键检查。永久回归包含半发行中断、最终 COMMIT 失败、同连接资格变化、锁竞争、旧 WAL 快照、UTC 换日、丢失响应、同键重放、片段版过期、代理权限变更和历史代表依赖。

最终集成复审结果待独立源码复验。
