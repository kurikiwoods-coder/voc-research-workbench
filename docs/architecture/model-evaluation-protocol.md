# 决策模型金标准与对照评估协议

P0 首次验收使用固定 `jev-1.14.0`，继承 J-1～J-14、G-1、G4 和 G5。新增决策模型、适配器协议变化或模型重大版本更新时，按获批用途制作独立评估与校准证据。Microsoft Decision 等候选进入比较前，先核实际 Model ID、接入、隐私、数据地区、原生概率和使用条款。[接口协议](ai-model-adapter-contract.md) · [现有需求矩阵](../requirements-matrix.md)

## 样本与分工

- 按原 M12 标准获得 100–200 条人工金标准。先标 50 条对齐分类、分档及问题判断规范，保留标注人、分歧率、裁决及记录。中文样本单独建子集和阈值。当试点语料无中文，依 J-3 在首批中文语料前补齐。
- 版本化保存项目、实际语义片段、跨句上下文、品类、来源、语言、注册表和题组。跨品类、已知、未知、低相似、否定、冲突和分档均应有适用覆盖。只评价当前经批准的证据类型和字段。
- 人工按题型独立标注后裁决。按表达发生或转载链分组，再划分校准与独立测试样本，避免同证据改写或上下文跨集导致泄漏。校准集用于拟合或选阈值，独立测试集用于报告。若用同一测试集反复调参，下一次正式报告使用新获准的独立测试集。
- J-14 的召回盲测采用至少 30 个已确认意图、至少两个产品品类。报告 Top-K、丢失正确项个案、None 守门、跨品类漏召与已知输入 Recall@K，试点目标 ≥95%，未达不放量。未知拒绝率独列。向量召回和决策分类分别核对。

## 运行与指标

| 验证项 | 记录与判定 |
|---|---|
| 真接口探针 | 锁定并核实际模型身份，核 Choice、Score、独立 Noul，完整概率范围与档位，Jev 11 题自动 8+3，实际用量与受控响应。缺字段或分片失败按 `schema_gap` / partial 记录。 |
| 分类与未知 | 准确率、Precision、Recall、Macro-F1、逐类或逐题 F1、未知拒绝率。分别披露测试集、样本量、覆盖、拒绝、漏召、错误强归类及无可用回执。 |
| 分档与问题 | 逐档分布与一致性、Score 划档差异、Noul 问题 F1、独立守门和人审结果。适用时报告 Brier Score 和 ECE，说明概率语义、计算方法、分箱、各类适用分母。 |
| 语言及迁移 | 同一获准测试集的总体结果与中文、英文、来源和跨品类子集结果。报告样本量、分母、未覆盖范围和分布变化。 |
| 运行表现 | 有效回执率、请求成功率、限流与错误、延迟分布、实际计费、币种与计费单位、人工复核比例。估算、未知和实际用量各自报告。 |
| 阈值与发布 | 记录模型、适配器、题组、注册表和索引，阈值与校准数据版绑定。报告阈值、低置信流转及复核规则，独立复审后由负责人按用途批准。原 G4/J 系列为正式门槛。 |

阈值和校准结果以各模型及版本单独验证。校准映射保持原概率可查，缺失分布保留缺口。模式 A/B 对同一获准输入和题组独立跑两次，按相同证据、样本框、语言与盲测版本对照。测试覆盖不足或汇总分歧时披露影响，评估回执保留独立域。主辅复核分别记录模型结果、授权及人工裁决。批准的备用模型按独立运行重新检查相应条件。

评估报告登记试验身份、语料来源及许可引用、样本切分、排除原因、版本和阈值、计量与人审负担、错误例、结论适用范围及审批结果。实际原始响应留在受控位置，外部报告仅投影授权证据和脱敏指标。M12-F 每批抽查 20 条并覆盖高/低置信，随注册表升版重校准，记录队列等待和积压。后续模型评估中心和双模型运行按另行授权落地。[生命周期与模式](model-lifecycle-and-calibration.md) · [ROADMAP-V2](../planning/ROADMAP-V2.md)
