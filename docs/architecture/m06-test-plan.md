# M06 反例推演与验收矩阵

以下保留 M06-A 的 24 个合成案例及 M06-B 修订后的预期。逐案复核、16 个追加测试夹具和两条对账断言见[独立反例](../evidence/m06-b/counterexamples.md)。案例中的“已发布”假设未来已具备正式准入、同版完整有效回执及审批，用于演算；当前正式口径为 unavailable/null。案例彼此独立。数对 (E,P) 依次为 N_eligible_dedup、N_published_classified；e1 等小写标识仅为示例证据。案例属于 DESIGN_CHECKED，正式实现属于 IMPLEMENTATION_NOT_TESTED。

**已有 C0-6 的证据边界。** [现有代码](../../src/discovery/recall.py)在内存 SQLite 建 2 产品、3 任务、30 合成意图；字符 TF-IDF(1–3)、20 维截断 SVD（seed 47）、归一化余弦，全局 Top-12 两次跨产品命中。输出 sklearn/索引/注册表版本、候选与分数，Choice 含 None，noul_guard 为标记。它只验证召回可跨产品，未实际调用独立 Noul 或以人工金标准评测召回。本轮依据代码和原验收记录，没有重新运行冒烟。后续 J-14 对已知样本用命中真实目标的数量除以适用已知查询数，未知样本及跨品类子集分别给分母，避免混用；模型最终分类另报 Macro-F1。

**实施后的工程边界。** 在隔离空库/v6 副本验证 FK、迁移崩溃与回退；双连接模拟撤销对写、到期、两人确认以及断连重放；契约测试检跨项目 404、失格 409、无权原文、工程/正式隔离；桌面与窄屏从筛选一路走至证据、撤销后重开。使用合成夹具验证的计数永远保留 synthetic 标记。以上不构成本轮业务测试或正式验收。

## 冻结政策的专项回归

以下为下一阶段应执行的断言，与原 40 例和实测原型分别记录。每次保留夹具、所用项目/版本、操作者权限、预期及实际；正式工程状态为 IMPLEMENTATION_TEST_REQUIRED。

| 政策 | 输入与操作 | 必须观察到的结果 |
|---|---|---|
| 1 身份 | 两条独立同文与一条出处断裂的疑似转引，以获准来源/品类分层，再核清转引 | 独立两次均保留；只暂停争议输入。核前分层列待核数、已评估数、待核率及缺项。敏感性上下界另列；合并须有事件及区间或转载链，旧版可回放。 |
| 2 产品 | 同一批两条明确边和一条撤销或比较对象不明的边；再以合法子集重试、重放并暂停提议规则 | 坏边造成零生效、零部分审核。合法批每边一条审核记录，原话与产品可核；相同命令不重复追加。仅人工确认可生效。规则/模型撤回按确切来源及版本找到影响边；对照组不受影响。 |
| 3 计数 | 使用 A13/A17/A18 与 B05–08，额外放入未切分撤销整行；比较获准旧口径、缺真实编码的项目、完整空切片 | 多异常一个主桶、次因可见；交叉过滤同 E，跨源/品类 distinct M。六桶和与主类和分别对账，排除单位可解释。缺前置正式数 null，完整空集 0，跨版比较显示口径和影响。 |
| 4 权限 | 两项目的私有字段放入可识别合成标记。六角色逐一遍历接口投影表，分别撤销跨项目专项授权和代表来源许可，重复取旧游标、旧幂等结果、历史报告与导出/出队 | 仅专项授权有效时可核原话；同一读者对隐藏对象与不存在对象观察一致，无计数、文本、排序、错误或摘要旁路。撤权只变读者投影，实际失格才暂停依赖用途。核治理登记及负责人通知范围；无关发布继续可用。 |
| 5 范围 | 两版目录含同名异 ID，旧自由串未解析，再经两职责复核绑定，随后提替代；分别查询旧报告、非产品范围及完整空切片 | 原冻结内容及 scope_version 不变。错映射版/目录组合拒绝；旧报告仍指原映射。已发布引用节点及祖先受保护，替代须记录影响并发新版本。unresolved、non_product 和真实零有不同表示。 |
