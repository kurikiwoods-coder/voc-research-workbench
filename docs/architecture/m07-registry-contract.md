# M07-A 意图注册表数据契约

M06 工程基线、五项冻结政策和 `M06-B-F.1` 继续适用。负责人于 2026-11-25 授权 M07-A 至 D 隔离开发。G-1 保持 BLOCKED，正式研究、编码、发布保持关闭。G-1-R-A/B 延期待单独授权。

## 权威定义

`m06_registry`、`m06_intent`、`m06_task` 和 `m06_intent_task` 继续提供封版、定义、稳定 ID 与主次任务的权威关系。同名定义可有不同 ID。历史引用锁定 `registry_version` 与定义 `version`。主类和次类来自同一边表，只有主类进入任务汇总。产品关联继续来自冻结范围和当前合格的原话证据。

共享投影只包括稳定定义 ID、版本、名称、定义、纳入与排除标准、主次任务、生命周期、问卷状态、安全版本信息及经过批准的正反例。问卷状态沿用 `unvalidated/validating/validated/failed`，独立于意图生命周期。旧版没有共享示例时返回空列表。项目原话、URL、来源计数、证据引用、审核理由及提出者通过受控项目入口访问。

历史 JSON 样例缺主任务时按 `pending_parent` 候选解析，保留可兼容的稳定 ID 和定义字段。旧 `representative_quotes`、`evidence_sources` 及历史变更理由不能充作已授权共享信息。恢复和草稿编辑以定义为输入，继续受实际证据和版本约束。

## 最小迁移设计

M06 封版事务要求新 `m06_registry` 版本在提交前封存。跨会话保存可修改草稿需要独立持久化。M06 现有定义表也没有获准共享的示例字段。顺序迁移 `008_m07_registry_drafts.sql` 新增三张项目私有表及一张版本化共享示例表，SQLite schema 升至 v8。

| 表 | 用途 |
| --- | --- |
| `m07_draft` | 项目、提案种类、基础注册表与当前修订指针。 |
| `m07_draft_revision` | 追加式定义、候选证据引用、操作理由、状态和提出者。 |
| `m07_draft_command` | 按项目和命令键保存输入摘要及已提交修订，支持事务内幂等重放。 |
| `m07_shared_example` | 绑定精确意图版本的正反例，封版前追加。审批引用留在库内，合成示例注明类型。正式录入由 M11 可信审核事务接续。 |

通过复合外键约束草稿、修订及命令的同项目关系。草稿保存使用现有写锁与外键机制。迁移不回填候选、不改写封版表、不更新统计热路径。诊断库和独立合成契约库仍用 v1。正式运行库须按既有发布及备份流程升级。
