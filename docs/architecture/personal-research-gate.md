# G-1-PERSONAL 最低准入政策

`G1_PERSONAL_POLICY = DOCUMENTED`，`G1_PERSONAL_IMPLEMENTATION = PARTIAL`，`G-1-PERSONAL = NOT_EVALUATED`。个人版使用一条独立正式准入记录。G-1-P-D 负责同批六项实证，G-1-P-R 负责独立安全复审与最终准入。通过后，个人版 M09 仍按负责人授权开工。商用版沿用原 G-1，个人版进度由自身准入决定。[负责人批准](../decisions/dual-edition-owner-approval.md) · [实施顺序](../planning/g1-personal-implementation-plan.md)

## 判定条件

个人研究正式使用须同时具备受信身份及明确用途、项目和来源资格、实际账户及调用通道审批、当前凭证版本、预算、同一验收批次六项证据及独立复审。部署方式、可用功能与研究发布按各自权限确认。准入与作用范围、有效期、策略版本和证据完整性绑定，经核准撤销或过期后重新判定。

| 检查 | 同一批次的最低证据 | 失败条件 |
|---|---|---|
| C0-1 固定模型与拆分 | 实际通道以 `jev-1.14.0` 运行获准输入，真响应核对精确模型，自动 11 题按 8+3 执行并按题号完整合并 | 请求、实际模型、分片或归属不符，保持阻塞 |
| C0-2 Choice、Score、Noul | 客户端保存可核对的脱敏实际响应，Choice 每选项、Score 每档概率、独立 Noul 概率及档位和题号齐全 | 缺字段记 `schema_gap`，不可由置信度、估算、其他片或其他模型补齐 |
| C0-3 搜索及原话 | 获准 Tavily 或 Brave 发现 URL，经受许可页面或接口回源，最少一条可核对真实用户原话，同时保存采集方式、用途、许可和回源 | 搜索摘要、合成正文、失格来源或无回查路径不能通过 |
| C0-4 真实用量与持久化 | 实际分片用量、预算及预约、SQLite 入账与回读、重启和幂等恢复。实际余额或明确未同步，费用与估算分列。一旦结果或扣费未知，先对账再决定 | 无真实计量、预算未拦截、单次计费重复、回执不一致或未知订单仍可发送均不通过 |
| C0-5 内部隔离及故障 | 合成内部标识在任何外部发送前拦截，实测断网、凭证异常、额度、契约错误、限流及上游故障。失败关闭并保留可审计状态 | 内部数据、敏感输入或权限失效仍可外发，或故障时绕过限制 |
| C0-6 三层与全局召回 | 按原标准验证 2 个产品品类、3 个任务大类和至少 30 个意图，关系完整，固定注册表与索引，Top-K 加 None 不超过 20 | ID 或关系无效、版本及候选不可追踪、按产品硬筛或 Choice 含 None 超限 |

C0-5 与 C0-6 按原规范使用隔离夹具并保留可重复检查的结果，与真实输入、回执和正式统计分域。C0-6 是召回冒烟，M12 的 J-14 和金标准仍独立验收。其他阶段的真实采样、M12 校准、M13 发布和 M14 问卷验证仍依原标准。[原验收矩阵](../requirements-matrix.md#可机读的需求映射)

## 证据复用

1. 为个人版开一项确定的正式验收批次，冻结项目、范围、用途、批准账户、凭证、模型、题组、证据摘要、规则版及窗口。六项在该批次逐项决议。允许的历史材料通过带来源、原批次、取证用途、摘要、有效期和复核者的只读引用纳入。规则不允许归入、用途或输入等级不同、停用、撤回、到期及无法重现时，该项继续挂起。
2. PackyCode 的合成 8+3 回执只证明原固定合成输入在当时通道上的模型、字段及实报用量能力。原费用补证可作为历史计量旁证。正式真实语料的调用、完整性、预算及回读须有适用的正式证据。旧通道或轮换凭证不得继承审批。
3. 既有 Tavily 搜索与真实原话可先核对搜索结果、回源路径、来源许可、原文摘要、查询与时间窗及用途。当前规则明确许可且可核验时，由新批次记录纳入决定。回源和许可无法重验时记缺项。工程夹具或受限快照不能填充真实原话。
4. 六项的当前证据不足时列明实际缺口。需要网络验收时，仅在 G-1-P-D 获得独立有期限的执行授权后运行最少必要的请求、预算和来源。原 PackyCode 合成授权已耗尽。原有历史账本保存原状态。[合成记录](../evidence/g1-rb-p/README.md) · [费用补证](../evidence/g1-rb-f/README.md) · [历史搜索证据](../evidence/p0-0/tavily-live/README.md)

## 预准入验收与最终放行

G-1-P-D 需要在最终放行前取证。未来服务端提供仅限该批次的验收执行授权，须在前置完成来源许可、账户、通道、脱敏、权限与预算，绑定期限、请求上限、证据摘要和凭证版本。在验证专用审计域执行，不能产生正式编码、发布回执或业务分母。需追加调用时由负责人另批。六项均有合格记录后仍须通过 G-1-P-R 的独立复审才可记录 `PASS`。任何必要条件缺失或失败保持关闭。

| 个人版门禁记录 | 必须保存 |
|---|---|
| 准入命名空间 | `edition=PERSONAL`、`gate_id=G-1-PERSONAL`、状态、策略版本、验收批次、复审结论，以及形成及失效时间 |
| 使用绑定 | 项目、冻结范围、用途、可信操作者及审核方、供应商、实际通道、固定模型、账户和凭证版、预算范围 |
| 审计引用 | 六项指向本机证据的受控引用、历史纳入决议、审批及有效期、可接受风险与撤销记录。投影仅展示授权范围内的最小信息 |
