# M08-A 来源适配与权限契约

来源描述包含稳定 ID、供应商、类型、适配器版本、M02 凭证引用、能力、启用状态、操作、精确域名、授权、许可引用、署名、留存、删除、限流与计费单位。适配器接受冻结范围下的查询计划，输出发现回执或页面回执。搜索和回源分别注册。同一契约供后续获准论坛、YouTube、Reddit、手工导入、Amazon 及 GitHub 来源接续。

| 操作 | 放行依据 |
|---|---|
| 搜索发现 | 已批准供应商与可外发查询范围，以及相应的访问与用量政策 |
| 原文访问 | 平台条款、API 通路及域名、路径和当前来源访问许可 |
| 原文存储 | 逐来源许可、允许字段、署名、留存及撤销或删除规则 |
| 研究使用 | M05 本项目当前结构化许可、来源和审核状态 |
| 外部模型传输 | G-1 正式准入、当前供应商审批、获准数据角色与脱敏 |

五项权限独立核验。未知、受限制、过期、已撤销、仅背景参考和内部材料均不授予正式原话处理权限。背景参考按单独角色和许可处理。受限通路需平台正式授权。夹具的访问批准只适用于合成页面。

先从 M03 读取 `(study_id, scope_id)` 并核对冻结时间及精确 `scope_version`。可选品类必须来自该版本，日期可以收窄已冻结窗口。研究对象及目标作为本机预览输入，登记品类仅限制计划范围。查询与适配器结果不确认产品、任务或意图关系。

| HTTP 接口 | 作用 |
|---|---|
| `GET /api/acquisition/sources` | 来源目录、独立权限状态及已配置搜索账户的 M02 本机诊断额度摘要 |
| `POST /api/acquisition/{study_id}/preview` | 本机校验冻结范围及合成查询并显示各引擎的参数和限制 |
| `POST /api/acquisition/{study_id}/demo` | 以固定合成文本执行发现和回源，从请求只接收范围及配置选择 |
| `POST /api/acquisition/{study_id}/collect` | 当前一律 403 |

这些接口经回环地址、Host、Origin 及操作头校验，响应带 `Cache-Control: no-store`。预览无持久化。已归档项目只可预览。演示不接收自由文本，使用固定模拟传输。正式来源的五项权限默认未知，界面标识模拟用量与 M02 本机诊断状态。

演示账本位于运行目录下 `m08-offline/acquisition.sqlite3`，版本 1。一个事务写入完整回执及清理策略，保存项目、范围、版本与规范化规则。最多保留最近 100 次演示，下次写入清理满 30 天的历史。可由本机文件管理直接清除整个演示账本。该账本与工作库 v8、诊断库和 PackyCode 预检库独立。

后续阶段在逐来源审批与 G-1 满足后，按 M04 批次登记及入库，经 M05 结构化许可与撤销，再在 M06 首次消费和投影时验证当前资格。原话处理使用 `CorpusStore.qualified_record(study_id, record_id)` 及受控写事务。发现回执和页面访问回执不创建原话记录、`mention_id` 或 `evidence_id`。未具备正式台账时，保持 M06-B-F.1 分母为 `null`。
