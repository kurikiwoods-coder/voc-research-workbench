# L5 Dashboard (仪表盘层)

Four modules on one page: sentiment (satisfaction / frustration / trust scored separately, cut by intent), issue detection (mention rate + average severity, same source and same denominator only), trend tracking (same-calibre weekly series), smart recommendations (trigger + evidence + action + verification method). Plus the low-confidence review queue view and the sampling funnel.

Status: design + interface definitions only. Not yet implemented (PDT v1.2 §9; P1).
