# L6 Outputs (输出层)

- `questionnaire.py` — questionnaire generator (discovery type → question type mapping, schemas/questionnaire-mapping.json); ODI ranking; simulated pretest; export to Google Forms.
- `report.py` — insight report export: pain / opportunity / risk / action, each with representative quotes and links.
- `reflow.py` — questionnaire responses flow back into L2; registry validation status is updated.

Status: design + interface definitions only. Not yet implemented (PDT v1.2 §10).
